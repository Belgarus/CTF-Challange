# Start
- Navigiere in den Challenge1 Ordner
- Starte einen localhost-Server: `python3 -m http.server 8000`
- Öffne die Index.html-Datei im Webbrowser: `http://127.0.0.1:8000/Index.html`
- Öffne die Developer Tools (F12 oder Rechtsklick → "Untersuchen")
- Navigiere zu **Konsole** → **Info**

# Regeln
- Bleibe im **Info**-Bereich – dort finden du alles, was du benötigst
- Nutze JavaScript, um an den Code zu gelangen

# Hinweise
- Der Code wird zwischen 161 und 9999 erzeugt (es werden nur Integer verwendet)
- Sobald Sie den Code erraten haben, wird jeglicher weitere Input ignoriert und das Passwort für die nächste Challenge angezeigt
